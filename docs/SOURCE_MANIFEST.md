# Source Manifest

## Backend

- FastAPI application, CORS, security headers, OpenAPI, and health endpoint.
- Argon2 password hashing, access/refresh JWTs, hashed rotating refresh sessions, authentication, user profile, and audit events.
- PostgreSQL/SQLite SQLAlchemy models, complete Alembic migration chain, Redis configuration boundary, Dockerfile, Compose stack, and demo seed.
- Bankroll balance/ledger and configurable per-ticket, daily, thesis, and loss-pause controls.
- Normalized provider contract and synthetic MLB, WNBA/basketball, soccer, football, and generic demo slates.
- Deterministic YWP scoring engine with probability, edge, EV, YIS, Vision, reliability, stability, variance, data quality, risk, and stake guidance.
- AIN/Strict Mode health record, sport-specific gates, reason codes, warnings, alternatives, invalidation, live trigger, hedge, Quick Cash, and Chain Reaction fields.
- Ticket Builder for all official, special, and ABC cards; thesis, script, player, Miss-by-1, and active-exposure controls.
- Draft ticket actions, weakest-leg removal, replacement, final Lock Check, expiring lock, and placement state.
- Result ledger with stake, P/L, closing odds/line, price CLV, line value, actual, signed miss distance, ticket-killer/final-leg markers, process/variance grades, assumptions, root cause, Quick Cash/Chain Reaction/live-trigger outcome, cash-out action/offer/time/reason, and lesson.
- Adaptive learning reports, confidence calibration, Miss-by-1 segmentation, bounded weight proposals, admin approval, versioning, and rollback.
- Backend unit/integration tests.

## Universal app

- Expo Router application for iOS, Android, and static web.
- Secure native token storage and web session storage, refresh rotation, login, registration, logout, and user scoping.
- Command Center, raw slate runner, Decision Board, official/special/ABC card views, Stay Away and quarantine views.
- Ticket Vault, weakest-leg removal, final Lock Center, placement control, in-app result/process/live-cashout audit entry, performance, calibration, Miss-by-1 Lab, learning guardrails, bankroll/risk settings, and protocol state.
- Original crest, minimalist logo, app icon, splash, favicon, reference art, black/gold theme tokens, and reusable branded components.
- Data-driven 1080 × 1350 PLAY/PASS graphic generation and native share/web download workflow.
- TypeScript, npm lockfile, Expo config, EAS build profiles, and environment template.

## Documentation and operations

- Root setup guide, architecture, API guide, canonical rules, brand system, protocol changelog, build/deploy guide, source manifest, and production checklist.
- GitHub Actions backend lint/test and mobile typecheck jobs.
- Root Makefile, Docker Compose, example environment, and ignore rules.

## Deliberately not embedded

- Live data-provider keys, sportsbook credentials, Apple/Google signing credentials, production domains, legal text approved for a particular jurisdiction, and data redistribution rights.
- A claim that any recommendation is guaranteed to win.
