# YWP OS — The Underdog Strategist

Local web app for the locked **Triple-Ticket Cushion Protocol**.

## Run

```bash
cd ywp-os
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Screens

- **Home** — brand hero
- **Protocol** — score legs (YIS), KEEP/HOLD/CUT, build Tickets A / B / C Fortress (floor ≥ 80)
- **Results** — log only after “placed” confirmation; grade win/loss later

Data stays in the browser (`localStorage`).
